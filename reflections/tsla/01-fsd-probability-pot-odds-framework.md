# Tesla 估值研究:从 SOTP 到扑克赔率框架

> 时间线:2026-05-11(V5C 3.3a 沉淀期内)
> 文件:[Tesla_估值锚定模型.xlsx](../../Tesla_估值锚定模型.xlsx)
> 性质:沉淀期内的「认知建设 + 方法论升级」,不构成调仓建议

## 一、为什么做这件事

V5C 3.3a 不直接持有 Tesla,但 QQQ 包含 Tesla ~3.5%,所以 V5C 间接持仓约 0.35%。

这次研究的核心目的**不是**判断 Tesla 该不该买,而是:

1. 建立对 Tesla 业务结构的 bottom-up 认知(承接 GOOG 估值的方法学)
2. **探索一种新的估值范式** —— 当估值依赖一个**单一不可证伪的二元事件**时,如何做决策?
3. 形成可季度跟踪的「业务监测仪表盘」

最重要的收获:**Tesla 教会我们一个新的估值框架(扑克赔率思维),适用于所有"叙事股"**。

## 二、Tesla 与 GOOG 的本质差异

GOOG 估值范式(沉淀期前段研究):
- 期权占比 < 1%(主营 $3,800B + 期权 $28B)
- 主营业务清晰可分,SOTP 自下而上
- DCF / EV/Sales 方法直接可用

Tesla 估值范式(本次研究):
- 期权占比 **21-50%+**(主营 $1,013B + 期权 $269-700B)
- 几乎所有未来价值都在「期权业务」(FSD 通用化 + Robotaxi + Optimus 等)
- **传统 P/E / EV/Sales 失效** —— TTM EPS = $1.09,P/E 320x
- 必须用 **SOTP + Real Option + 概率决策框架** 三层

这是从「现金流估值公司」到「叙事估值公司」的范式跃迁。

## 三、研究的演进路径

```
Step 1: 财报解读       → Q1 2026 实际数据 (TTM $97.88B)

Step 4: 核心期权深挖   → Robotaxi 单位经济(发现严重低估)
Step 5: FSD 通用化重估 → 「人是懒惰的」洞察,FSD 跨业务杠杆
Step 6: 概率核心问题   → FSD 通用化概率分析(技术/监管/Musk track record/竞争)
Step 7: 扑克赔率框架   → 关键转折:从猜概率到算赔率
Step 8: 数据化框架     → Sheet 8 完整决策矩阵
Step 9: 多框架一致性   → 发现并修复 Sheet 8 内部不一致
```

**每一步都揭示了上一步的不足,并产生新的方法论补丁**。

## 六、关键洞察 1:Robotaxi 严重低估

### 单位经济对比(Uber vs Tesla)

```
Uber 5 英里行程:
  乘客付 $15,司机 $10.50,Uber 净 $4.50(净利率 10-15%)

Tesla Robotaxi 5 英里行程:
  乘客付 $8.25(便宜 45%),Tesla 全部 $8.25
  成本 $2(能源+折旧+维护),净 $6.15(净利率 75%)
```

**结构性差距**:Tesla 价格便宜 45% 同时净利率 7-8x Uber。

### 重估 Robotaxi 价值

```
当前 SOTP: $500B 上限 × 40% = $200B 期望

基于单位经济推导:
  2031 全球 Mobility 市场: ~$330B
  Tesla 各情景:
    Bear (15% 份额): $40B 营收 × 10x P/S = $400B
    Base (30% 份额): $120B × 12.5x = $1,500B
    Bull (50%+新需求): $300B × 12x = $3,300B
  
加权: 0.30×400 + 0.50×1500 + 0.20×3300 = $1,530B (2031)
折现今天: $950B → 保守 × 0.7 = $665B

修订后期望: $500-700B (vs 当前 $200B)
```

**Robotaxi 应该是 Tesla 估值的 50%+,而不是 20%**。

## 七、关键洞察 2:FSD 通用化是「跨业务杠杆」

「**人是懒惰的**」 — 用户原话。

如果 FSD 真正可靠(L4+):
1. **Auto Sales 销量爆炸** — Tesla 不再是 EV 品牌,而是「会自己开的车」品类
2. **FSD 订阅渗透率 14% → 60%+** — 25M 车队 × 60% × $150/月 = $27B/年 订阅
3. **Robotaxi 自营网络** — 已在 Sheet 6
4. **二手车残值提升** — 降低 TCO,推动新车销量
5. **保险/充电协同** — Network 效应

**FSD 通用化不是单一期权,是「重估所有业务的杠杆」**。

## 八、关键洞察 3:这是一个无法证伪的二元事件

### 概率分析的四维证据

**技术(支持 vs 反对)**:
- 支持: V14 关键脱离率 1,454 英里(3x V13)+ Coast-to-coast 零干预 + Cortex 2 + AI5
- 反对: Waymo 14,000 英里/脱离(Tesla 落后 10x)+ vision-only 长尾问题
- 概率估计: **55-65%**

**监管(支持 vs 反对)**:
- 支持: NHTSA Spring 2026 立法 + Texas/CA 已是 L4 友好
- 反对: state-by-state patchwork + 中国延期 + EU 保守
- 概率估计: **50-55%**

**Musk 时间线兑现纪录**:
- 10 年承诺"明年实现 FSD",**10 年全部失约**(2016-2026)
- 2026 Q1 财报:"无监督 FSD Q4 2026"(第 10 次同样承诺)
- 概率估计: **36%**(终极成功 60% × 5 年内 60%)

**竞争**:
- Waymo: 技术领先但商业模式弱
- Cruise: 几乎退出
- 中国玩家: 国际化困难
- Tesla 全栈优势: 独占

**综合概率(非独立修正)**: P(FSD Level A by 2031) = **25-40%**(中位 ~35%)

**市场隐含 P(A)**: **55-65%**(从当前估值反推)

## 九、关键洞察 4(范式转换):扑克赔率框架

### 用户原话(重要)

> **"我们是在对人类是否能创造出一个真正独立完成任务的智能体下注,
> 没有内幕消息和足够的专业知识的我们无法确定这个概率,
> 那么是否可以套用德州扑克里的打法,根据赔率来下注,
> 这似乎是我们唯一的选择了"**

### 框架核心

**不需要判定真实概率,只需要判定**:
- 我的估计区间(25-55%)
- 盈亏平衡概率(46%)
- 我的估计是否高于盈亏平衡

```
盈亏平衡 P(A) at $428:    46.0%
我的 P(A) 估计:           40.0%  
距离:                     -6pp

决策: ❌ 避免买入(明显 -EV)
Kelly 比例: -9.1%(负值,不持有)
```

### 三情景估值(修订后,与 SOTP 一致)

| 情景 | 含义 | 今天公允 |
|---|---|---|
| A. FSD 通用化成功 | SOTP Bull + 期权全实现 | **$2,300B** |
| B. 部分实现 | SOTP Base + 期权部分 | **$1,100B** |
| C. 失败(回归汽车)| SOTP Bear + 期权失效 | **$550B** |

### 概率-价格双向矩阵(核心决策工具)

**在不同 P(A) 假设下的合理单股价**:

| P(A) | 公允单股 | 当前 $428 偏离 | 决策 |
|---|---|---|---|
| 20%(强烈悲观)| $340 | +26% | ❌❌ 强避免 |
| 30% | $374 | +15% | ❌❌ 强避免 |
| 40%(我的) | $408 | +5% | ❌ 避免 |
| 46%(盈亏平衡)| $428 | 0% | ➖ 中性 |
| 55% | $459 | -7% | ⭐ 买入 |
| 65% | $493 | -13% | ⭐⭐ 强买入 |

### 价格 Zone(我的 P(A) = 40%)

| Zone | 价格范围 |
|---|---|
| ⭐⭐ 强买入区 | < $374 |
| ⭐ 买入区 | $374 - $391 |
| ✅ 边际买入区 | $391 - $408 |
| ⚠️ 警惕区 | $408 - $425 |
| ❌ 避免区 | $425 - $459 |
| ❌❌ 强避免区 | > $459 |

**当前价 $428 在「避免区」** — 等价格跌到 $391 以下才考虑建仓。

## 十一、模型内部不一致的发现与修复

研究中段,用户发现 Sheet 8 与 Sheet 3 数字不一致,逼出**第二次方法论升级**:

### 三个 Section 三种不同的 gap 定义

| Section | 隐含 gap 定义 | 问题 |
|---|---|---|
| Section 三 决策 | 我 P(A) - break-even at current | 主决策 |
| Section 四 (我的"错误修复")| 我 P(A) - 行 P(A) | 错误(混合了两个变量)|
| Section 五 | 我 P(A) - 必需 P(A) | 正确(与 Section 三一致)|
| Section 八 原版 | 偏离 = current/fair - 1 | 用任意倍数, 不一致 |

**正确逻辑**:所有矩阵都用「**离 break-even 多少 pp**」作为统一 gap。

### 修复后所有矩阵一致

```
Section 三:     gap -6pp → ❌ 避免
Section 四 (40%): gap -6pp from 46% → ❌ 避免
Section 五 ($428): gap -6pp → ❌ 避免
Section 八 ($428 in $425-$459): → ❌ 避免区
```

## 十二、本次研究产生的原则候选

### 原则 #28(候选):面对不可知概率事件,使用赔率框架而非概率框架

> 不需要判定真实概率,只需要判定: 我的估计与盈亏平衡的距离。
> 如果不能确定地高于盈亏平衡,就不下注 — 等价格走到 +EV 区间再说。

适用场景:
- Tesla(FSD 通用化)
- 加密货币(国家信用崩塌)
- 单一新药(临床三期)
- AGI(何时实现)

### 原则 #29(候选):多框架估值时,必须显式验证各框架的隐含假设是否一致

> SOTP Bear/Base/Bull 是「业务表现维度」
> FSD-centric A/B/C 是「单一事件维度」  
> 两者概率分配 + 期权处理 + 情景定义必须显式对齐,否则得到相互矛盾的结论

### 原则 #30(候选):多 Sheet 决策表必须共享同一个 gap 定义

> 「Gap = 我 P(A) - 行 P(A)」给一种决策
> 「Gap = 行 P(A) - break-even」给另一种决策
> 「偏离 = 现价/公允 - 1」给第三种决策
> 三者数学相关但语义不同,所有矩阵必须用同一种,且与 master 决策一致

### 原则 #31(候选):叙事股估值的「期权占比」决定方法选择

> 若主营/期权 > 90/10: 用传统 SOTP + EV/Sales(GOOG 模式)
> 若 50/50: 用 SOTP + Real Option(Tesla 模式)
> 若 < 30/70: 用概率决策树为主,SOTP 为辅(纯叙事股)

## 十五、模型局限性(诚实记录)

### 局限 1:三情景值是主观估计

A/B/C 的 $2,300B / $1,100B / $550B 是基于 SOTP + 期权条件实现度的推导,但每个数字都有主观假设:
- A 假设期权全实现 → 实际可能只实现 60-80%
- C 假设主营 Bear + 期权完全失效 → 但 Tesla 现金 $45B 是「底价支撑」

### 局限 2:概率本身有不确定性

P(A) = 40% 不是精确值,真实值可能在 25-55% 区间。Kelly 计算用单点 40%,但应该用区间敏感性。

### 局限 3:5 年时间窗可能不够

FSD 通用化可能 7-10 年才完全实现,5 年视野可能低估终极价值。

### 局限 4:Cross-impact 未建模

期权之间有相关性(FSD 成功推动 Robotaxi 推动 Cybercab),Sheet 6 当作独立加和,可能高估。

### 局限 5:不考虑 Musk 个人风险

如果 Musk 因健康/法律/政治原因离开 Tesla,所有期权概率会下调 10-15pp。模型未单独处理。

## 十七、一句总结

GOOG 研究教会我们「**估值是假设的镜像**」(原则 #19)。

Tesla 研究教会我们「**对不可知概率事件,用赔率而非概率**」(原则 #28)。

这两个原则共同构成 V5C 哲学下「**面对不确定性的认知工具箱**」。

```
GOOG: 看清你已经持有什么(认知建设)
Tesla: 看清你不应该主动持有什么(决策纪律)

二者合一: 在不动手的前提下,理解整个市场
```

V5C 3.3a 沉淀期的最高境界,不是发现更好的投资,而是**理解为什么不需要更多投资**。
