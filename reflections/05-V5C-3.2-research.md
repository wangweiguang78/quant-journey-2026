## 第二段：CAPE-Forward Returns 经验关系

你的挑战让我承认：我之前的"大概率不会重复"是**懒惰措辞**。

**真正的实证依据**是：

### Shiller CAPE 与后续 10Y 实际回报的历史关系

| 起始 CAPE | 历史 10Y 后续年化 |
|---|---|
| 5-10x | 11-15% |
| 15-20x | 7-9% |
| 25-30x | 3-5% |
| **30-35x** | **1-4%** |
| **>35x** | **-1% to +2%** |

**当前**：
- SPX CAPE ~36x
- NDX P/E ~33x
- 经验关系预测下一个 10Y SPX 年化 **2-5%**

### 主流买方研究的对应预测

- **Goldman Sachs** 2024：SPX 未来 10Y 年化 3% 名义
- **GMO**（Grantham）：美股大盘未来 7Y 实际回报 -2.5%
- **Vanguard** 2025：未来 10Y 年化 3-5%
- **AQR**：CAPE-based model 预测 SPX 4.5%

**这是有实证支撑的预测，不是"未来不会重复过去"的空话**。

但要诚实说：**这是概率分布的中位数预测，不是确定性结果**。
反例存在（日本 1990 后 CAPE 高但持续下跌；美国 2010 之后 CAPE 高但反而上涨）。

## 第三段：核心认知升级——"分散投资不是为了择时"

### 你的提问

> "考虑到目前高估值前提下，我们是否应该僵化采用平均分配比例的方式构建组合？
> 或者像 Buffett 一样，持有大量现金，牺牲短期利益等待长期机会？"

### 我提供的三派对比

**1. 静态再平衡派（Yale, Bogle）**
- 信念：未来不可预测，纪律高于一切
- 实证：Yale 35 年年化 12-13%

**2. 估值倾斜派（GMO, Hussman）**
- 信念：起始估值决定回报
- **残酷实证**：Hussman 2010 起预测崩盘，**15 年累计 -30%**（同期 SPX +500%）

**3. Buffett 实际做法（≠ 大众想象）**
- 现金不是择时工具，是流动性 reserve
- 2010-2024 Berkshire **跑输 SPX 2-3pp/年**
- 现金 cash drag 是**真实代价**，不是免费的灵活性

### 你的回答（**这是整个项目最深刻的认知**）

> **"分散投资不是为了回避选错标的，更不是为了择时，
> 如果有能力择时，分散投资岂不是反向操作！"**

> "我们组合里所有资产都有底层逻辑支撑，是经得起时间考验的。
> 即使在顶点买入，立即遇到风险，也在测试数据范围之内，
> 也有现金来抄底，从而增加收益率。"

### 这句话的三层含义

#### 第一层：分散与择时是相互否定的

| 信念 | 必然推论 |
|---|---|
| "我能择时" | 集中持有最优标的 + 全仓进出 |
| "我不能择时" | 分散 + 静态权重 + 机械再平衡 |

**不能两者同时持有**：
- 如果你相信能择时却选择分散 = 自我矛盾
- 如果你相信分散却试图择时 = 反向操作

#### 第二层：再平衡 ≠ 择时

```
择时（错误）:  "我预测市场会跌 → 我减仓"
再平衡（正确）: "权重偏离阈值 → 机械执行调整"
```

**关键区别**：
- 择时基于**预测**
- 再平衡基于**规则**
- 再平衡的"低买高卖"是**机械化的副产品**，不是预测的结果

#### 第三层：高估值 ≠ 必须减仓

V5C 3.1 的 50/30/20 结构**已经体现了估值警觉**：
- 50% 不在股票里（30% 对冲 + 20% 防御）
- 不是 "100% 进攻 - 临时减仓 30%"
- 是 "永远 50% 进攻 - 50% 非股"

**这是结构性纪律，不是动态择时**。

## 第五段：永久原则总结

V5C 项目至此提炼出 **8 条永久原则**：

### 第一条：样本期决定结论
不存在"客观正确"的回测期，只有"最相关于未来"的回测期。

### 第二条：真分散 vs 假分散
"加几个股票" ≠ 分散。**真正分散的依据是相关性数据**，不是名字看起来不同。

### 第三条：设计质量 > 维护勤勉度
设计错的组合再勤维护也救不回。
**应该花时间在"设计是否对"，而不是"如何优化已有组合"**。

### 第四条：纠错纪律比纠错本身重要
正确的纠错 = 严谨研究 + 延迟执行 + 再次验证。
**立刻纠错可能犯更大错**。

### 第五条：配置目的决定标的选择
单股的目的是远高于指数的 alpha。
**找不到合适的，就不放进来——空缺比次优好**。

### 第六条：Hedge 要真反相关，不是"另类"
"分散"不等于"对冲"。平时表现不同 ≠ 危机时表现不同。
**真正的对冲只有 5 类**：现金 / 长债 / 黄金 / 趋势跟随 / 显式尾部对冲。

### 第七条：未来不会重复过去 ≠ 论据
"历史不会重复"是空话。**真正的论据是具体经验机制**——
比如"起始估值与后续回报的负相关关系"（Shiller CAPE 实证）。
任何对未来的预测都应该写清楚机制，并承认它是**概率分布而非确定性**。

### 第八条：分散投资不是为了择时（**整个项目最重要的认知**）
> 如果有能力择时，分散投资岂不是反向操作！

分散 = 对"无法择时"的承认。
再平衡 = 把"贵了卖、便宜买"机械化。
**两者不能与"主动择时"思维并存**。
- 选择分散就要彻底放弃择时
- 选择择时就要彻底放弃分散

> **低相关性资产即使自身 Sharpe 较低，加大权重仍可提升组合整体 Sharpe**——直到对冲过度成为新拖累。

### 公式背景（夏普分解）

数学上，组合 Sharpe 提升不只是"加权平均 Sharpe"，还有"diversification 项"：

```
组合 Sharpe ≈ Σ(wi × Sharpe_i) + 多元化项 × Σ(1 - ρ_ij)
```

其中 ρ_ij 是资产间相关性。当 ρ_ij 接近 0，多元化项是显著正贡献。

DBMF 的 0.186 相关性使其"多元化项"贡献远大于其自身 Sharpe 损失。
