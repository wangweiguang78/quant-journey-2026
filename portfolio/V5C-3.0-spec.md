## 关键设计决策与数据依据

### 1. AVUV / SCHD 移除
- **测试**：26 年长周期相关性分析。
- **结果**：与 VOO 相关性 0.85–0.94，无分散价值。
- **决策**：完全移除。

### 2. BME → HQH 整合
- **问题**：BME 与 HQH 同为医疗 CEF，存在 ROC 重叠。
- **决策**：保留 HQH（医疗 CEF）+ XLV（医疗 ETF）的双层结构。

### 3. 黄金 20% — 长周期数据验证保留
- **测试**：14.6 年（2011–2026）多元对冲方案对比。
- **结果**：

| 变体 | Sharpe | MaxDD |
|---|---|---|
| 基准 (黄金 20%) | **0.793** | -19.14% |
| 金减半 + VNQ5+TIP5 | 0.763 | -21.38% |
| 金小减 + VNQ2.5+TIP2.5 | 0.784 | -19.54% |
| 金大减 (激进) | 0.759 | -21.39% |
| 现金减半 + TLT10 | 0.795 | -19.12% |
| 复合方案 | 0.761 | -20.88% |

- **结论**：所有"减金"方案恶化 Sharpe 与 MaxDD。黄金 20% 是最优配置。
- **个人备注**：原本对黄金抵触，但数据否决了主观偏好。

### 4. 50-30-20 结构（非 50-25-25）
- 将 5pp 从原"防御"转入"对冲"，强化对冲层抗通胀+抗黑天鹅能力。

### 5. 单股选择 — 圈内原则
- GOOG / AMZN 各 5%，基于 Buffett 圈内能力原则。
- Bessembinder 2018 基率风险（4% 个股贡献全部财富）通过严格圈内 + 5pp 上限 + 独立止损规则共同抑制。

## 个股仓位的特殊规则（继承 V5C 2.0）

V5C 3.0 中包含两支个股 GOOG + AMZN（各 5%），不能套用 ETF 的标准再平衡规则。

### 个股专用规则
- ✓ 涨太多触发再平衡卖出（同 ETF 规则）
- ✗ **跌太多 NOT 触发"加仓"再平衡**（破坏对称）
- ✓ 设独立止损：
  - 单股跌 -40% from peak → 减仓到目标权重的 50%
  - 单股跌 -60% from peak → 完全清仓

### 原因
个股（vs ETF）存在归零风险。
ETF 内部自动剔除衰落公司，可以放心再平衡。
个股需要独立止损规则防止 averaging-down 陷阱。
